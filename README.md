# TechSolutions

Сайт-візитка компанії TechSolutions. Курсовий проєкт із дисципліни «Основи WEB-дизайну».

## Стек
- Node.js + Express 5 (сервер)
- MongoDB (база даних, через рідний драйвер mongodb)
- Vanilla HTML/CSS/JS на фронті

## Запуск локально
1. `npm install`
2. Створи `.env` за зразком `.env.example` (вкажи `MONGODB_URI`)
3. `npm start`
4. Відкрий http://localhost:3000
